# Sistema CRUDJava
Um sistema simples e funcional de **CRUD** (Create, Read, Update, Delete) desenvolvido em Java para consolidação de conceitos fundamentais da linguagem e Programação Orientada a Objetos (POO).

---

## 📌 Sobre o Projeto

Este projeto consiste em uma aplicação Java focada no gerenciamento e manipulação de dados em memória/console. Foi criado para demonstrar a aplicação prática de:

- **Estruturas de Dados:** Manipulação de coleções de dados (`List`, `ArrayList`, etc.).
- **Programação Orientada a Objetos:** Abstração, Encapsulamento, Herança e Polimorfismo.
- **Entrada e Saída de Dados:** Interação via terminal utilizando a classe `Scanner`.
- **Tratamento de Exceções:** Garantia de estabilidade contra entradas inválidas do usuário.

---

## ⚙️ Funcionalidades

- [x] **Criar (Create):** Cadastrar novos registros com validação de dados.
- [x] **Listar (Read):** Exibir todos os registros cadastrados ou buscar por ID/nome.
- [x] **Atualizar (Update):** Alterar informações de registros existentes.
- [x] **Deletar (Delete):** Remover registros do sistema.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Java (JDK 17+)
- **IDE recomendada:** Visual Studio Code / IntelliJ IDEA / Eclipse
